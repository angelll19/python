# Tips Dataset Analysis

This project explores the `tips` dataset using exploratory data analysis and a simple linear regression model. The notebook investigates how tip amounts relate to factors such as total bill, gender, smoking status, day of the week, time, and group size.

## Overview

The analysis focuses on understanding tipping patterns and identifying trends in the dataset. It includes data cleaning, summary statistics, visualizations, correlation analysis, and a basic regression model to examine relationships between variables.

## Objectives

- Clean and inspect the dataset
- Explore tipping patterns by gender, smoking status, day, and time
- Analyze the relationship between total bill and tip amount
- Examine how group size affects spending and tipping
- Build a simple regression model to predict tip amount

## Key Findings

- There is a positive relationship between total bill and tip amount.
- Male customers generally leave higher tips than female customers in this dataset.
- Smokers tend to give slightly higher tips, although the result varies by subgroup.
- Sundays and Saturdays show higher tipping activity.
- Larger groups tend to spend more and leave higher tips.
- The regression model has limited predictive power due to the small dataset and limited number of variables.

## Notes

This project is an exploratory analysis of a small dataset. The results should be interpreted carefully because the dataset is limited in size and may not represent broader tipping behaviour.
